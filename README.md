# Supreme Events Website

A responsive, multi-page static website for Supreme Events in Owerri, Imo State. Built with HTML, CSS and vanilla JavaScript, with no build step required.

## Pages
- `index.html` — Home, service highlights, and selected reviews
- `services.html` — Event planning, coordination, and consultation
- `feedback.html` — Feedback and enquiry form
- `styles.css` — Responsive design and styling
- `script.js` — Mobile navigation, current year, and WhatsApp form handling

## Deploy to GitHub and Vercel
1. Download and extract this ZIP.
2. Create a new GitHub repository.
3. Upload the files inside the extracted folder (not the ZIP itself). Keep `index.html`, `services.html`, `feedback.html`, `styles.css`, and `script.js` at the repository root.
4. In Vercel, select **Add New → Project** and import the GitHub repository.
5. Select **Other** as the framework preset if asked. Leave build command and output directory empty, then deploy.

## Feedback form
The feedback form opens WhatsApp with a pre-filled message. Visitors must press Send in WhatsApp to submit it. The website does not store messages or provide a database. A backend or form service is required for stored submissions.
